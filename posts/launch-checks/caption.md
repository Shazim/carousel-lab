## Caption (paste this)

about 5,000 ai-built apps were found leaking data. four checks before you launch yours. save it.

a scan of roughly 380,000 apps built on lovable, replit, base44 and others found about 5,000 exposing sensitive data.

check 1 — log in as one user and change the id in the address bar to another user's. if their data loads, stop and fix it.

check 2 — search the code that runs in the browser for secret keys. publishable keys are fine. secret and service-role keys, never.

check 3 — on supabase, turn on row level security for every table, then test it with a second account.

check 4 — in test mode, double-click pay and drop your connection mid-payment. one charge, every time.

bonus — restore a backup once, before you ever need it.

these checks are most of what the extra money buys in a $15k build over a $5k one.

not sure what yours would show? send me a message and i'll tell you where i'd look first.
