The Vitamin Pack

Five systems that let one founder run like a team. Each one below has the 20% that matters, a starter build you can ship this weekend, and the mistake that kills it. Tools assumed: Claude + n8n (or Zapier/Make — the shapes are identical).

AAutomations

Admin is a tax you can stop paying.

Starter build — the follow-up machine

  • Trigger: new lead lands (form, DM export, email label).
  • Step 1: n8n webhook catches it, writes the lead to a sheet/CRM.
  • Step 2: Claude drafts a personal first reply from the lead's own words.
  • Step 3: draft lands in your inbox for a one-tap send. No reply in 3 days → polite nudge drafted automatically.
You are my follow-up assistant. Lead's message: [PASTE]
What we sell: [OFFER] Tone: warm, direct, zero corporate filler.
Draft a 4-sentence reply that references their exact words,
answers the one question they actually asked, and ends with a
single concrete next step. Do not oversell. Think step by step.
The mistake: automating the send. Agents draft, you send — one rule keeps quality and trust intact.

BBuild in public

Proof beats promises — especially when you sell builds.

Starter build — the weekly proof loop

  • Monday: one screenshot of the thing on your screen right now (behind-the-scenes).
  • Wednesday: one before/after — old flow vs new flow, old number vs new number.
  • Friday: one lesson that cost you something. Failures out-perform wins.
  • Batch all three from a 15-min voice note: Claude turns the transcript into three drafts.
The mistake: posting outcomes without the mess. The mess is the content. Polished-only feeds read as ads.

CClaude

One model, four jobs, running while you sleep.

Starter build — Claude on cron

  • Code: Claude Code for the MVP work you already do.
  • Content: a nightly job drafts tomorrow's post from your notes file.
  • Customer replies: first-pass drafts for every new ticket/DM (see Vitamin A).
  • Cron: schedule each job. Every draft waits in a folder for your morning review.
Read my notes file below. Write tomorrow's post for founders
who want AI automation. Format: hook line, 3 short lines of
substance, one question at the end. My voice: plain words,
no hype, lowercase. Notes: [PASTE NOTES]
The mistake: prompting live every time. The wins compound when prompts are saved, versioned, and run on a schedule.

DData

You cannot fix what you cannot see.

Starter build — the daily digest

  • One sheet with 5 numbers max: leads in, replies sent, calls booked, cash in, top drop-off.
  • n8n pulls the numbers every morning at 7:00.
  • Claude writes a 5-line digest: what moved, what stalled, the one thing to push today.
  • Digest arrives wherever you already look (email/Telegram/Slack).
The mistake: building a 30-widget dashboard you never open. Five numbers you read daily beat fifty you don't.

EEmail

The only audience the algorithm can't take away.

Starter build — magnet → welcome → weekly

  • Magnet: package one thing you already built (this pack is one). Keyword comment → DM → link.
  • Welcome: 3 short emails — the story, the best build, the offer. Claude drafts, you edit once, it runs forever.
  • Weekly: one build, one lesson, one link. Repurposed from Vitamin B — nothing written twice.
The mistake: waiting until you "have something to sell." The list is the asset; start it before you need it.
